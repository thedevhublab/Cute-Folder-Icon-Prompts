# Create a Cute macOS Folder Icon from a Reference Character

Use the user-provided character image as the primary reference and transform it into a cute, high-quality macOS folder icon.

## 1. Preserve the Reference Character

- Identify and preserve the character's defining features, including its silhouette, colors, facial features, proportions, accessories, and distinctive visual traits.
- Maintain the original character's identity and recognizable appearance.
- Do not replace the reference character with a different animal, mascot, or generic character.
- Do not assume any specific species, color palette, personality, or theme in advance.
- If multiple reference images are provided, use them together to understand the character's appearance.

## 2. Integrate the Character into a Folder

- Design a recognizable folder shape with the character naturally incorporated into it.
- The folder should retain the familiar silhouette of a desktop folder, including its main body and upper tab.
- Make the character and folder feel like a single, cohesive 3D object rather than simply placing a flat character image on top of a folder.
- Adapt the character's features creatively to fit the folder structure while keeping the character recognizable.
- The character can peek out of the folder, become part of its front surface, or interact with its shape, depending on what best suits the reference.
- Choose the most visually appealing composition based on the supplied character rather than following a fixed template.

## 3. Visual Style

- Use a polished, cute, high-quality 3D aesthetic with soft materials, rounded edges, subtle depth, and smooth surfaces.
- Apply soft studio lighting, gentle ambient occlusion, and natural contact shadows.
- Derive the color palette and decorative details from the reference character.
- Make the design charming, distinctive, and visually cohesive.
- Avoid excessive decoration, visual clutter, sharp edges, or overly realistic textures.
- Ensure the character remains recognizable when the icon is displayed at a small size.

## 4. Output Requirements

- Square 1:1 composition.
- Transparent background with genuine alpha transparency.
- One centered folder icon only.
- Full folder silhouette visible, with sufficient padding around the edges.
- High-resolution rendering suitable for use as a macOS desktop folder icon.
- No text, lettering, labels, watermarks, mockups, desktop screenshots, or unrelated objects.

## 5. Creative Decision-Making

Use the supplied character as the source of truth. Make independent design decisions about the folder color, material, composition, and character integration based on the reference.

The final result should look like a custom-designed, adorable 3D macOS folder icon featuring the user's specific character.

Prioritize character fidelity, folder recognizability, visual quality, and a clean silhouette over unnecessary decorative details.
